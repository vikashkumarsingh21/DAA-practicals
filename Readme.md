## 📖 About the Repository

<br>

> *"An algorithm must be seen to be believed."* — Donald Knuth

<br>

**DAA-Lab** is a structured, academically rigorous repository built to document and showcase practical implementations covered in the **Design and Analysis of Algorithms (01AI0506)** laboratory course, part of the **5th Semester** curriculum for **B.Tech Computer Science Engineering (Artificial Intelligence & Machine Learning)** at **Marwadi University**.

<table>
<tr>
<td width="33%" valign="top">

### 🎓 Course Overview

A hands-on laboratory course focused on translating algorithmic theory — complexity analysis, recurrence relations, and design paradigms — into working, testable code.

</td>
<td width="33%" valign="top">

### 🎯 Repository Purpose

To serve as a **single source of truth** for all DAA practicals, organized cleanly by topic, language, and output — built for revision, reference, and reproducibility.

</td>
<td width="33%" valign="top">

### 🧠 Learning Goals

Master **sorting, searching, dynamic programming, greedy strategies, and graph algorithms** while strengthening dual-language (C & Python) implementation skills.

</td>
</tr>
</table>

<br>

> [!NOTE]
> Every practical in this repository includes **source code**, **sample output**, and **documentation** — organized into isolated, self-contained folders for clarity and easy navigation.

## ⚙️ Installation Guide

<br>

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/vikashkumarsingh21/DAA-practicals
```

### 2️⃣ Navigate into the Repository

```bash
cd DAA-Lab
```

### 3️⃣ Navigate to a Specific Practical

```bash
cd Practical-01
```

<br>

### 🔧 How to Run C Programs

```bash
# Navigate to the C folder of a practical
cd C

# Compile the program
gcc bubble_sort.c -o bubble_sort

# Run the compiled executable
./bubble_sort        # Linux / macOS
bubble_sort.exe       # Windows
```

> [!TIP]
> Use `gcc -Wall -o output filename.c` to compile with all warnings enabled for cleaner debugging.

<br>

### 🐍 How to Run Python Programs

```bash
# Navigate to the Python folder of a practical
cd Python

# Run the script
python3 bubble_sort.py
```

> [!TIP]
> Ensure Python 3.x is installed and added to your system's PATH before running any script.

## 📊 Time & Space Complexity

<br>

### ⏱️ Time Complexity Table

<div align="center">

| Algorithm | Best Case | Average Case | Worst Case |
|:---|:-:|:-:|:-:|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) |
| Linear Search | O(1) | O(n) | O(n) |
| Binary Search | O(1) | O(log n) | O(log n) |
| Factorial (Recursive) | O(n) | O(n) | O(n) |
| 0/1 Knapsack | O(nW) | O(nW) | O(nW) |
| Matrix Chain Multiplication | O(n³) | O(n³) | O(n³) |
| Making Change | O(n·amount) | O(n·amount) | O(n·amount) |
| DFS / BFS | O(V + E) | O(V + E) | O(V + E) |
| Prim's Algorithm | O(E log V) | O(E log V) | O(E log V) |
| Kruskal's Algorithm | O(E log E) | O(E log E) | O(E log E) |
| Floyd-Warshall | O(V³) | O(V³) | O(V³) |
| Travelling Salesman (DP) | O(n²·2ⁿ) | O(n²·2ⁿ) | O(n²·2ⁿ) |

</div>

<br>

### 💾 Space Complexity Table

<div align="center">

| Algorithm | Space Complexity | Notes |
|:---|:-:|:---|
| Bubble / Selection / Insertion Sort | O(1) | In-place sorting |
| Merge Sort | O(n) | Requires auxiliary array |
| Quick Sort | O(log n) | Recursive call stack |
| Heap Sort | O(1) | In-place with heap structure |
| Linear / Binary Search | O(1) | Constant extra space |
| Factorial (Iterative) | O(1) | No recursive stack |
| Factorial (Recursive) | O(n) | Recursive call stack |
| 0/1 Knapsack | O(nW) | 2D DP table |
| Matrix Chain Multiplication | O(n²) | 2D DP table |
| Making Change | O(amount) | 1D DP table |
| DFS / BFS | O(V) | Visited array + queue/stack |
| Prim's Algorithm | O(V + E) | Adjacency list + priority queue |
| Kruskal's Algorithm | O(V + E) | Edge list + Disjoint Set |
| Floyd-Warshall | O(V²) | Distance matrix |
| Travelling Salesman (DP) | O(n·2ⁿ) | DP with bitmasking |

</div>

## ⚖️ Algorithm Comparison Table

<br>

<div align="center">

| Paradigm | Approach | Example Algorithms | Optimality |
|:---|:---|:---|:---|
| **Divide & Conquer** | Break problem into subproblems, solve recursively | Merge Sort, Quick Sort | Optimal for comparison sorts |
| **Greedy** | Choose local optimum at each step | Prim's, Kruskal's, Making Change | Globally optimal (for matroid-like problems) |
| **Dynamic Programming** | Store subproblem results, avoid recomputation | Knapsack, MCM, Floyd-Warshall, TSP | Guaranteed optimal |
| **Brute Force** | Try all possibilities exhaustively | Linear Search, Naive TSP | Optimal but inefficient |
| **Graph Traversal** | Systematic exploration of nodes/edges | DFS, BFS | Complete traversal guarantee |
